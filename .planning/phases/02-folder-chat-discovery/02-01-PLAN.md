   - Import `getMarkedPeerId` from `@mtcute/core`
   - Combine `pinnedPeers` and `includePeers` arrays
   - Filter out `inputPeerEmpty` and `inputPeerSelf`
   - Use `getMarkedPeerId()` to convert each InputPeer to marked ID
   - Return array of chat IDs (numbers)

4. Export `FolderInfo`, `listFolders`, `getChatIdsFromFolder`, and also re-export raw folder type from result for Plan 02 to access.
