  <files>src/folders/index.ts</files>
  <action>
Extend `src/folders/index.ts` with:

1. `selectFolders(folders: FolderInfo[]): Promise<number[]>` function:
   - Import `multiselect`, `isCancel` from `@clack/prompts`
   - Call multiselect with:
     ```typescript
     const selected = await multiselect({
       message: 'Select folders to track:',
       options: folders.map(f => ({
         value: f.id,
         label: `${f.title} (${f.chatCount} chats)`
       })),
       required: true
     })
     ```
   - If `isCancel(selected)`, call `process.exit(0)`
   - Return selected as `number[]`

2. `diffChatLists(stored: number[], current: number[]): { added: number[], removed: number[] }` function:
   - Create Set from stored and current
   - added = current IDs not in stored
   - removed = stored IDs not in current
   - Return { added, removed }

3. `syncFolderConfig(tg: TelegramClient): Promise<void>` function:
   - This is the main orchestration function for the folders command
   - Call `listFolders(tg)` to get all folders
   - Call `tg.getFolders()` again to get raw filters (for getChatIdsFromFolder)
   - Import and call `loadConfig()` from config module
   - Check if `config.trackedFolders` is empty:
     - If empty (first run): call `selectFolders()` to let user pick folders
     - If not empty: use existing tracked folder IDs
   - For each tracked folder ID:
     - Find the raw filter from getFolders result
     - Call `getChatIdsFromFolder()` to get current chat IDs
     - If folder existed in config, call `diffChatLists()` and log changes:
       - For added: `console.log(\`New chat: ${id}\`)`
       - For removed: `console.log(\`Removed chat: ${id}\`)`
     - Update config with current chat IDs
   - Call `saveConfig()` to persist
   - Log summary: "Tracking X folders with Y total chats"

Note on chat names: Per research, getting chat names requires additional API calls. For this phase, just log chat IDs. Phase 3+ can add name lookup if needed.

Export `selectFolders`, `diffChatLists`, `syncFolderConfig`.

2. Add folders command after auth command:
   ```typescript
   program
     .command('folders')
     .description('List and select Telegram folders to track')
     .action(async () => {
       const sessionPassword = await password({
         message: 'Enter session password:',
         mask: '*'
       })

       if (isCancel(sessionPassword)) {
         cancel('Cancelled')
         process.exit(0)
       }

       const tg = createClient(sessionPassword as string)

       try {
         await tg.connect()

         // Check if authenticated
         const { ensureAuthenticated } from './auth.js'
         await ensureAuthenticated(tg)

         // Sync folder config
         await syncFolderConfig(tg)

       } finally {
         await tg.close()
       }
     })
   ```

3. The command flow:
   - Prompts for session password (same as auth command)
   - Creates and connects client
   - Ensures user is authenticated (reuses auth flow if needed)
   - Calls syncFolderConfig which handles:
     - First run: shows folder list, prompts selection, saves config
     - Subsequent runs: loads config, detects and logs changes, updates config

Import `ensureAuthenticated` from auth.js if not already imported.
