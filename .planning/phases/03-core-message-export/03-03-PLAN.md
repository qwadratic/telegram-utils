  <action>
Create src/messages/index.ts to orchestrate the complete export flow.

Implementation:

1. Export `exportChats(tg: TelegramClient, config: Config): Promise<ExportResult>`

   Where ExportResult is:
   ```typescript
   interface ExportResult {
     chatsExported: number
     chatsSkipped: number
     messagesExported: number
     durationMs: number
   }
   ```

2. Flow:
   - Start timer with `Date.now()`
   - Initialize spinner from @clack/prompts
  - Get all chat IDs from config.trackedChatIds (deduplicate)
   - For each chat ID:
     a. Update spinner: `Exporting chat N of M...`
     b. Fetch all messages using fetchMessages generator, collecting into array
     c. Update spinner on progress callback: `Chat N: fetched X messages...`
     d. When waiting for rate limit, update spinner: `Rate limiting: waiting 1.5s...`
     e. If no messages, log "Skipping empty chat: {chatId}" and continue (per CONTEXT.md)
     f. Call writeMonthlyFiles with the messages
     g. Track counts
   - Stop spinner with success message
   - Return ExportResult

3. For getting chat name:
   - Use `tg.getChat(chatId)` to fetch chat info
   - Extract title/name for display and filename
   - Handle errors gracefully (use chat ID as fallback name)

Key imports:
```typescript

import { spinner } from '@clack/prompts'
import { Config } from '../config/index.js'

import { writeMonthlyFiles } from './writer.js'
```

Note: The spinner should show rate limit waits explicitly as decided in CONTEXT.md.
